# Final Project (Random Hero Generator)

## Project Description

This is a random hero generator, for mostly just knowledge purposes. The hero resets every page refresh, and contains heroes from multiple IP's, anyone from Spider-man and Batman, to Harry potter and Gollum. Future functionality would be to add the ability to make predictions on hero battles to earn xp to level up your account.
